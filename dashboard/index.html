3. Recommended R&D project: T2 AI-driven bogie digital twin

What: vibration/temperature/strain sensors on the bogie + live twin + AI (fault diagnosis, real-time curve dynamics, maintenance timing). Like a smartwatch for the bogie.

Why now (TRL 5, Adjacent): components validated in lab (Zhang TRL4, Dong TRL5, Mutlu TRL3-4); no fleet demo yet, so overall TRL 5 - the EU funding sweet spot (lab to pilot). Builds on BLUE bogie/simulation core for the same rail clients; predictive service itself is new.

Evidence: Zhang 2026 (AI) • Dong 2026 (twin) • Mutlu 2026 (decision)

Demo data (proxy, not TRL evidence): Kaggle bogie vibration dataset for dashboard charts. Real pilot would use fleet data.

Route: ~750k/year internal (4% of 18.7M turnover) + EU co-funding (Europe's Rail JU / Horizon Europe) for a 24-month pilot from TRL 5 to 6-7 on a regional fleet.
